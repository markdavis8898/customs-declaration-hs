# Customs Declaration HS Code Tool

Harmonized System (HS) code lookup and **customs declaration** helper for import/export classification.

## Features

- Quick HS code search by product description
- Duty rate estimation
- Customs documentation checklist
- Country-specific import requirements

## Usage

```bash
python3 hs_lookup.py --search "computer parts"
```
